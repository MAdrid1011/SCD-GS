# Git Commit Message Tags

- `[cleanup]`: Remove obsolete, private, generated, or out-of-scope material.
- `[docs]`: Change public contracts, architecture documentation, figures, or trace fixtures.
- `[rtl]`: Change the executable reference model, Chisel implementation, or integrated verification.
- `[tests]`: Change tests only, with no implementation or contract change.
- `[build]`: Change build, tooling, or repository configuration only.
