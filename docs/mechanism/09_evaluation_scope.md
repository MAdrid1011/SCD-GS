# Evaluation Scope

This repository releases an inspectable mechanism implementation. It includes
no private manuscript, model source, dataset, checkpoint, hardware profiler
capture, platform-calibration artifact, result table, or PPA report.

The supplied tests establish only deterministic semantic correspondence on
synthetic records: state transitions, path decisions, counters, transaction
shape, and canonical-update feedback. They cannot establish reconstruction
quality, scene coverage, runtime, energy, area, timing closure, or a result
from any specific device.

Paper-reported experimental values remain provenance in the manuscript. Public
commands intentionally produce mechanism checks rather than performance data.
