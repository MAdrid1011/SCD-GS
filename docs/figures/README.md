# Public Figures

`scdgs-five-stage.drawio` is the editable source for the public SCD-GS
five-stage dataflow figure. Its PNG, SVG, and PDF exports show the same
mechanism contract as `../mechanism-contract.md`: SIU confirmation, a current
user/training view paired with the StateSPM response before CIU, global TRU
ordering, and TUU feedback.

Regenerate the exports with Draw.io after changing the source. Keep the figure
mechanism-focused. It must not add platform, workload, performance, energy, or
quality claims that the public artifact cannot reproduce.
